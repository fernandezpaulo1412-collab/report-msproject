# Report MS Project

Aplicación de escritorio para Windows que analiza programas de obra de **Microsoft Project** (`.mpp`)
para inspección técnica (ITO) y oficina técnica.

- **Resumen ejecutivo** — avance físico real vs programado, SPI, valor ganado y proyección de término.
- **Curvas S** — física y financiera: planificada (línea base), programa vigente y avance real.
- **Ruta crítica** — tareas críticas y casi críticas (holgura 0 a 5 días).
- **Atrasos y holguras** — variación de término por tarea contra línea base; holguras negativas y excesivas.
- **Recursos y HH** — sobreasignaciones, histograma por período y curva acumulada de mano de obra.
- **Revisión ITO** — 19 controles de calidad del programa (criterios tipo DCMA-14) con puntaje 0–100.
- **Informe semanal ITO** — exportable a Word y PDF.
- **Complemento para MS Project** — pestaña propia en la cinta: analizar el programa abierto, importar
  un presupuesto de Excel y armar APU que deja los recursos de costo en la tarea.

**Gratis.** No necesita tener instalado Microsoft Project ni Java: el instalador trae todo.
Los archivos se procesan localmente en tu equipo, no se suben a internet.
